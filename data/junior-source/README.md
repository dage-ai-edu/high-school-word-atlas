# 初中专属词表筛选说明

本目录记录“初中专属词光”的词表来源与筛选结果，方便后续复核和增补。

- 教材范围：七年级上、七年级下、八年级上、八年级下、九年级上，共 5 册英语教材的课后单词表。
- 当前收录：1,457 个与 Word Atlas 官方词库精确匹配的唯一词条。
- 匹配原则：只采用精确匹配和可核验的 OCR 结果，不使用模糊匹配强行补词。
- 未覆盖：资料库中没有九年级下册英语课本；官方词库不存在或 OCR 无法可靠识别的教材词也暂未收入。

文件说明：

- `word-match-audit.csv`：每个已收录词首次出现的教材、PDF 页码及全部来源。
- `unmatched-candidates.csv`：未自动收录的候选词，包含真实缺词、专有名词与 OCR 噪声，必须人工复核后才能增补。
- `match-summary.json`：本次筛选的数量摘要。
- `junior-word-ids.json`：构建专属词库时使用的词条 ID 顺序。

教材 PDF 不随项目分发。重新构建时，将环境变量 `JUNIOR_TEXTBOOK_LIBRARY` 指向按本项目约定目录结构整理的教材库。
